▶ How to Use This System — A quick reference guide for navigating the system.
Step 1
Define Materials
First, set up each raw material you use — its name, category, unit, and reorder level. This just describes the material; it doesn't add any stock yet.
Step 2
Receive Lots
Stock comes in by receiving lots. Each lot records a quantity, lot number, and dates. A material's on-hand total is the sum of its lots, shown on Raw Materials.
Step 3
Build Recipes
A recipe lists the materials and amounts needed to make one unit of a product. A recipe must exist before you can create a batch of it.
Step 4
Create Batches
To produce a product, create a batch from its recipe. You pick which lots to draw from, and that stock is deducted. The batch becomes Ready (or Planned if you set a future completion date).
Step 5
Ship Batches
Group one or more Ready batches into a Shipment. Creating the shipment marks those batches as Shipped and moves them to the Shipped list.
Step 6
Manage & Export
Each section has a Manage page to edit or delete records. Most list pages also have an Export Excel button at the top right to download a spreadsheet.
Defining a new material
  1. Go to Add Material.
  2. Enter the name, category, and unit (kg, g, bags, etc.).
  3. Set a Reorder Level — the on-hand amount at which it's flagged as low stock.
  4. Tick Edible / Organic if they apply (these drive the Organic batch label).
  5. This only defines the material — add actual stock by receiving a lot.
Receiving stock (a lot)
  1. Go to Receive Lot.
  2. Enter the material name (it must already be defined), lot number, and quantity.
  3. Add the received date, plus expiry, location, supplier, and cost if you have them.
  4. The quantity is added to that material's on-hand total. View and edit lots under Manage Lots.
Creating a recipe
  1. Go to Add Recipe.
  2. Enter the product name and optional notes.
  3. Add each material the product needs and the quantity per unit.
  4. Save it — the recipe is now available when creating batches.
Creating a batch
  1. Go to New Batch.
  2. Type the product name (it pulls from your recipes) and the quantity.
  3. Choose which lot(s) to draw each material from — that stock is deducted.
  4. Leave Planned Completion Date blank for a Ready batch, or set a future date to create a Planned one.
  5. Batch Type is usually Standard; use Component/Finished only for housemade sub-batches.
Shipping batches
  1. Go to Shipments and click Create Shipment.
  2. Add a destination/notes, then tick the Ready batches to include.
  3. Click Create Shipment — those batches are marked Shipped.
  4. Shipped batches appear under Shipped; manage shipments at Manage Shipments.
Editing or deleting a record
  1. Use the Manage page for that section: Materials, Lots, Batches, Recipes, or Shipments.
  2. Click Edit to update details.
  3. Click Delete to remove it permanently.
  4. Deletes can't be undone — double-check before confirming.
Responding to low stock
  1. Go to Low Stock.
  2. Everything listed is at or below its reorder level.
  3. Export the list to Excel if you need to share it.
  4. To restock, receive a new lot for that material.
Exporting to Excel
  1. Go to any of: Raw Materials, Low Stock, Batches, Shipped, or All Recipes.
  2. Click the Export Excel button at the top right.
  3. A spreadsheet downloads to your computer automatically.
  4. Individual shipments also have an Export Manifest button on their detail page.
Good to know & in case of emergency:
The data is safe and backed up nightly — a full copy of all company data is stored every night in case of emergency The Audit Log records every change made — useful if something looks off Reorder Level is just a threshold you set — the system doesn't automatically order anything Stock only enters by receiving a lot, and a material's on-hand total is the sum of its lots Recipes need to exist before you can create a batch that uses them Batches flow Planned → Ready → Shipped; shipping happens by adding Ready batches to a Shipment If the page looks wrong, try refreshing before assuming it's a bug In case of emergency — if data is altered beyond manual fixing, contact the admin to restore the database from a nightly backup
